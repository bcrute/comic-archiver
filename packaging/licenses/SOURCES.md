# Where these license texts come from

The apps carry these texts because the software they cover is built into the apps but does not ship its own
license file there. Each is copied unchanged from the source named here; replace it from the same place when
the version changes.

| File | Covers | Source |
|---|---|---|
| `GPL-3.0.txt`, `LGPL-3.0.txt` | Qt and PySide6 (desktop) | https://www.gnu.org/licenses/ |
| `Apache-2.0.txt` | AndroidX, Jetpack Compose, Kotlin and kotlinx.coroutines (Android) | https://www.apache.org/licenses/LICENSE-2.0.txt |
| `python-3.14.txt` | CPython 3.14 and the code it incorporates (desktop) | `Doc/license.rst` at tag v3.14.8 of https://github.com/python/cpython |
| `python-3.13.txt` | CPython 3.13 and the code it incorporates (Android) | `Doc/license.rst` at tag v3.13.16 of https://github.com/python/cpython |
| `bzip2.txt`, `expat.txt`, `libedit.txt`, `libffi.txt`, `liblzma.txt`, `libuuid.txt`, `mpdecimal.txt`, `ncurses.txt`, `openssl.txt`, `sqlite.txt`, `zlib.txt` | Libraries built into Python | `python/licenses/` of python-build-standalone `cpython-3.14.8+20261009-x86_64-unknown-linux-gnu-pgo+lto-full.tar.zst` |
| `zstd.txt` | Zstandard, built into Python 3.14 | `LICENSE` at tag v1.5.7 of https://github.com/facebook/zstd |
| `zlib-ng.txt` | zlib-ng, built into the Linux Python | `LICENSE.md` at tag 2.2.5 of https://github.com/zlib-ng/zlib-ng |
| `chaquopy.txt` | Chaquopy, which runs Python on Android | `LICENSE.txt` at tag 17.1.0 of https://github.com/chaquo/chaquopy |
| `android/<package>/` | The Python packages in the Android app | The package's own license file, as installed in the app |
