Comic Archiver

To start it, double-click "Comic Archiver" in this folder. If you used the
installer instead, Comic Archiver is in your Start menu.

Windows may ask whether you want to run it, because it does not come from
the Microsoft Store. Choose "More info" and then "Run anyway".

Your saved library is the folder "Comic Archiver" in your user folder.
