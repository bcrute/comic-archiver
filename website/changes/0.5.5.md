- **Choose which comics and novels to download.** The Library page now has a checkbox for each title, with **Check all** and **Uncheck all** at the top. On Android, use **Library → Episodes**. Everything starts checked, including after an update. Check all includes future discoveries; Uncheck all leaves future discoveries unchecked too, until you choose them. Choices are kept separately for each provider and working library. Episode-type and extras settings still apply within checked titles.
- **Saved files stay yours to manage.** Unchecking a title keeps its existing CBZ/EPUB files and extras. You can remove them yourself. The app skips unchecked titles during downloads. Changes pause an active download while the new choices are saved and then let it continue. A paused download stays paused. After installing an update, the queue and saved files remain, and acquisition waits for **Continue**.
- **Optional update checks.** Open **Settings → About → Check for updates** to check manually, or choose automatic checks once a day. Automatic checks start **off**. Manual checks leave that preference unchanged. Checks contact this website for a small version file and send no sign-in, account or library information; the website host receives the usual connection information, including your IP address. Available updates link to the download page; the app does not install them automatically.
- **One Backblaze sharing choice.** Choose **Use the same settings for all providers** on the Backblaze setup page. The provider selector appears below it only when separate settings are selected. Existing connection details are retained.
- **Metered connections on desktop.** If you previously allowed metered or mobile connections, turn that option on again after updating. The app now saves this choice on the computer, so opening a library from another device starts with the unmetered-only setting.
- **Windows keeps cached originals after saving an archive.** This keeps a recovery copy if Windows loses the newly saved archive or its metadata during a power failure. The cache can use additional disk space.
- **Tapas purchase history can recover from an expired pager.** If Tapas rejects the current page with HTTP 400, the desktop app tries once from the first page and keeps the history check marked incomplete if the retry fails.
- **Smaller support emails.** Support logs are limited to 128 KiB and include the parser reason for recent EPUB failures when available.
