- **Choose which comics to download.** The Library page now has a checkbox for each recorded comic, with **Check all** and **Uncheck all** at the top. On Android, use **Library → Episodes**. Everything starts checked, including after an update. Check all includes future discoveries; Uncheck all leaves future discoveries unchecked too, until you choose them. Choices are kept separately for each provider and working library. Episode-type and extras settings still apply within checked comics.
- **Saved files stay yours to manage.** Unchecking a comic does not delete its existing CBZ/EPUB files or extras. You can remove them yourself; unchecked comics are not automatically downloaded again. Changes pause an active download while the new choices are saved and then let it continue. A paused download stays paused. After installing an update, the queue and saved files remain, and acquisition waits for **Continue**.
- **Optional update checks.** Open **Settings → About → Check for updates** to check manually, or choose automatic checks once a day. Automatic checks start **off**. Manual checks leave that preference unchanged. Checks contact this website for a small version file and send no sign-in, account or library information; the website host receives the usual connection information, including your IP address. Available updates link to the download page; the app does not install them automatically.
- **One Backblaze sharing choice.** Choose **Use the same settings for all providers** on the Backblaze setup page. The provider selector appears below it only when separate settings are selected. Existing connection details are retained.
