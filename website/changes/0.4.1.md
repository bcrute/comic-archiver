date: 2026-11-11

- **A first version for Mac.** Comic Archiver now runs on Macs with an Intel processor. Apple has not notarized it, so macOS asks you to allow it the first time. Macs with Apple silicon are not supported yet.
- **Fewer downloads that stop partway.** A download no longer pauses because a site's own episode count disagrees with its episode list. An episode the site has removed or left empty is set aside so the rest can finish, and **Continue** tries the set-aside episodes again. When a site is down, the download waits and carries on without giving up on its episodes.
- **A clearer dashboard.** Site cards are larger, with their status, estimates and transfer rate easier to read, and the window shows a change as soon as it has happened.
- **Libraries on more Windows drives.** A library can be kept on a drive that stores no access permissions, such as an exFAT or FAT32 external drive.
- **More novel chapters saved.** Chapters with tables whose cells span rows or columns are saved as EPUB.
- **Moving a library is safer.** A move that was interrupted carries on after a restart, and no sign-in or cloud key is left behind in a half-moved folder.
- **Lighter on your disk.** The app reads the library less often while it works, which matters most on hard disks and large libraries.
