Installing and updating

Install and update

The app is signed for updates and installed from an APK file outside Google Play. Follow these steps only for the file linked on this page or the official GitHub release. Compare it with the checksums above if you need to verify the file; an installation warning alone does not establish whether it is safe.

  1. On the phone, tap Download the app. If the browser warns that the file might be harmful, choose Download anyway.
  2. Open the downloaded file. If Android says your phone isn't allowed to install unknown apps from this source, choose Settings, turn on Allow from this source, then go back.
  3. Choose Install. If Google Play Protect warns about the app, choose More details, then Install anyway.

To update, download the new version and install it over the old one; don't uninstall first. You stay signed in, and your settings and saved episodes stay.
